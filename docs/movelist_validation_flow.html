MoveList 校验算法流程

本页描述当前校验器使用的时间轴扫描算法，以及 Pick、Place、PreTrans、Prepare、 Complete、Process、PrePrepare 这七类 move 的完整检查项。字段名称与 docs/interface_doc.txt 和 src/validation 当前实现保持一致。

总体流程 公共规则 MoveType 逐 Move 检查 PreMoveID 压力态 错误分类

1. 总体流程

1. 建立索引 建立 MoveID -> move、机器人、模块、槽位、可达性、时长和 PreMoveID 反向消费索引。
2. 时间轴排序 按 StartTime, EndTime, MoveID 从前往后扫描，并维护已见 move 与已完成 move。
3. 校验当前 move 先查字段，再查 init data 合法性，最后查必须的前置 move 是否在 PreMoveID 里。
4. 更新时间轴状态 Pick/Place 更新材料位置；Process 更新加工状态；PrePrepare 更新压力或环境状态。
5. 图与压力态复查 全局检查 PreMoveID 引用、重复、自环、环路和 LoadLock Pump/Vent 访问冲突。
判定前置完成的核心条件是： previous.EndTime <= current.StartTime + tolerance。如果当前 move 依赖的前置 move 尚未结束，即使它出现在 PreMoveID 里，也应判为非法。

2. 公共规则

公共字段检查

  • MoveID 必须为正整数，且全局唯一。
  • MoveType 必须属于当前支持范围。
  • StartTime 和 EndTime 必须为有限数字。
  • EndTime >= StartTime。
  • ModuleName 非空。
  • PreMoveID 必须为整数列表；无前置使用空列表。
  • 所有槽位字段必须是正整数列表。
  • 多片字段按 index 对齐，例如 Mat、Step、PJob、RobotSlot、Station、Slot。

init data 检查

  • 引用的机器人必须存在于 Robots。
  • 引用的模块必须存在于 Stations。
  • 槽位必须落在 Slots 内；无 Slots 时使用 1..Capacity。
  • 机器人 arm 必须启用，并且可达访问模块。
  • SlotsStationMap 存在时，robot slot 与 station slot 映射必须合法。
  • 模块和槽位的 TimeToAvailable 不得晚于实际使用时间。
  • 实际动作时长必须匹配 init data 中的配置时长。

3. 当前使用的 MoveType

接口枚举还包含 MultiPick(2)、MultiPlace(3)、Swap(4)、PostComplete(8)、Align(11)。 当前校验器尚未覆盖这些类型；输出中出现时应按不支持类型报错。

0 PickMove 1 PlaceMove 5 PreTransMove 6 PrepareMove 7 CompleteMove 9 ProcessMove 10 PrePrepareMove

4. 每种 Move 的所有校验情况

PickMove

0
类别校验项不合法情况
字段 必须有 Robot、RobotSlotList、SrcStationList、SrcSlotList、MatIDList。 缺字段、空列表、槽位不是正整数、材料为空。
init Robot 存在；源模块存在；源槽位属于源模块；机器人可达源模块；robot slot 合法。 机器人未知、模块未知、不可达、slot 不在 Slots/Capacity 内。
时长 EndTime - StartTime == Robot.PickTime[src_station]。 Pick 时长与 init data 配置不一致。
状态 开始时源 station slot 有对应 Mat；robot slot 为空；模块和机器人可用时间已到。 源槽无片、Mat 不一致、robot slot 被占用、资源尚不可用。
前置 需要同源站槽的最近 Prepare(6)、同机器人且目标等于源站槽的 PreTrans(5)、同源站的 PrePrepare(10)。 缺少必要 PreMoveID；前置尚未完成；前置站点不是 Pick 源站。

PlaceMove

1
类别校验项不合法情况
字段 必须有 Robot、RobotSlotList、DestStationList、DestSlotList、MatIDList。 缺字段、空列表、槽位不是正整数、材料为空。
init Robot 存在；目标模块存在；目标槽位属于目标模块；机器人可达目标模块；robot slot 合法。 机器人未知、模块未知、不可达、slot 不在 Slots/Capacity 内。
时长 EndTime - StartTime == Robot.PlaceTime[dest_station]。 Place 时长与 init data 配置不一致。
状态 开始时 robot slot 持有对应 Mat；目标 station slot 可放入；模块和机器人可用时间已到。 robot slot 无片、Mat 不一致、目标槽被占用、资源尚不可用。
前置 需要同目标站槽的最近 Prepare(6)、同机器人同材料且目标一致的 PreTrans(5)、同目标站的 PrePrepare(10)。 缺少必要 PreMoveID；前置尚未完成；前置目标不是 Place 目标站。

PreTransMove

5
类别校验项不合法情况
字段 必须有 Robot、RobotSlotList、SrcStationList、DestStationList；带片时应有 Mat 和源/目标槽位。 缺 Robot、缺源/目标站、robot slot 非法；带片信息无法和位置对应。
init Robot 存在；源站和目标站存在；机器人可达源站与目标站；robot slot 合法。 机器人未知、模块未知、源/目标不可达。
时长 EndTime - StartTime == Robot.PrepTransTime[src,dest]；存在 TransType 时按 TransType 精确匹配。 找不到配置时长，或实际时长与配置不一致。
状态 空载时机器人当前位置应可从源站移动；带片时 robot slot 中材料必须等于 MatIDList。 机器人当前指向不一致、带片材料不一致、机器人尚不可用。
前置 带 Mat 时需要同机器人、同源站、同材料的最近 Pick(0)；不带 Mat 时需要同机器人最近 Pick(0) 或 Place(1)。 缺少必要 PreMoveID；前置尚未完成；Pick 源站不是 PreTrans 源站。

PrepareMove

6
类别校验项不合法情况
字段 必须有 ModuleName、SlotList、RelatedActionType、RelatedRobotType；不应包含 Robot。 模块为空、slot 非法、station move 带 Robot。
init 模块存在；SlotList 属于模块合法槽位；模块状态允许准备动作。 模块未知、槽位越界、模块处于不可操作状态。
时长 由后续消费它的 Pick/Place 决定：Pick 使用 PickPrepareTime[robot]，Place 使用 PlacePrepareTime[robot]。 实际时长与对应 PrepareTime 不一致。
状态 Prepare 期间模块槽位不能和互斥动作非法重叠；LoadLock 转换中不可访问。 同槽位并发准备/取放/关门冲突，或 Pump/Vent 期间访问。
前置 需要同站槽最近的 Complete(7)、Process(9) 或 PrePrepare(10)。 前一次关门、加工完成或环境准备未声明/未完成。

CompleteMove

7
类别校验项不合法情况
字段 必须有 ModuleName、SlotList、RelatedActionType、RelatedRobotType；不应包含 Robot。 模块为空、slot 非法、station move 带 Robot。
init 模块存在；SlotList 属于模块合法槽位；模块状态允许完成动作。 模块未知、槽位越界、模块处于不可操作状态。
时长 由前置 Pick/Place 决定：Pick 使用 PickCompleteTime[robot]，Place 使用 PlaceCompleteTime[robot]。 实际时长与对应 CompleteTime 不一致。
状态 Complete 作用的槽位必须是刚发生 Pick/Place 的槽位；期间不能与互斥动作冲突。 站槽不一致、并发冲突、LoadLock 转换中访问。
前置 需要同站槽同材料最近 Pick(0) 或 Place(1)，并需要同站槽最近 Prepare(6) 如果存在。 缺少必要 PreMoveID；前置尚未完成；前置站槽与 Complete 站槽不一致。

ProcessMove

9
类别校验项不合法情况
字段 必须有 ModuleName、SlotList、ProcessRecipe；产品片工艺需要 Mat、Step、PJob。 模块为空、slot 非法、recipe 缺失、产品片身份不完整。
init 模块存在；slot 合法；ProcessRecipe 存在且适用于该模块。 模块未知、槽位越界、recipe 不存在或模块不匹配。
时长 EndTime - StartTime == ProcessRecipe.Time + MoveTimeOffset[ProcessMove]。 实际加工时长与 recipe 或 offset 不一致。
状态 开始时站点槽位必须持有对应 Mat；晶圆 route step 必须匹配 recipe。 槽位无片、Mat 不一致、Step/recipe 不匹配、模块尚不可用。
前置 需要同站槽最近 Complete(7)；Process 带 Mat 时，Complete 也必须对应同一 Mat。 缺少 Complete 前置；前置尚未完成；前置材料或站槽不一致。

PrePrepareMove

10
类别校验项不合法情况
字段 必须有 ModuleName、SlotList、LastState、CurState、PrePrepareType；不应包含 Robot。 模块为空、slot 非法、状态缺失、station move 带 Robot。
init 模块存在；slot 合法；LoadLock 压力态目前只允许 ATM 与 VAC。 模块未知、槽位越界、状态不是 ATM/VAC。
时长 LoadLock 使用 PumpTime、VentTime 或 PrePrepareTime 中匹配类型的 Time。 找不到配置时长，或实际时长与配置不一致。
状态 LastState 必须等于模块当前状态；转换期间同一 LoadLock 不允许 Pick/Place/Prepare/Complete 访问。 压力链断裂、转换重叠、转换中访问。
前置 需要同模块最近 PrePrepare(10)，以及同站槽最近可能占用槽位的 Complete(7)、Pick(0) 或 Place(1)。 缺少压力链或占用链前置；前置尚未完成；previous.CurState != current.LastState。

5. PreMoveID 边规则

当前 MoveType 允许的前置 MoveType 额外一致性
Pick(0) PreTrans(5), Prepare(6), PrePrepare(10) Prepare 必须是 Pick 源站槽；PrePrepare 必须是 Pick 源站；PreTrans 目标必须等于 Pick 源站槽。
Place(1) PreTrans(5), Prepare(6), PrePrepare(10) Prepare 必须是 Place 目标站槽；PrePrepare 必须是 Place 目标站；PreTrans 目标必须等于 Place 目标站槽。
PreTrans(5) Pick(0), Place(1) 带 Mat 时要求同机器人、同材料；由 Pick 触发时源站必须一致。
Prepare(6) Pick(0), Place(1), Complete(7), Process(9), PrePrepare(10) 同站槽最近的关闭、加工完成或环境准备必须先完成。
Complete(7) Pick(0), Place(1), Prepare(6), PrePrepare(10) 前置站槽必须和 Complete 站槽一致；带 Mat 时材料必须一致。
Process(9) Complete(7) 同站槽最近 Complete 必须存在；带 Mat 时材料必须一致。
PrePrepare(10) Pick(0), Place(1), Complete(7), PrePrepare(10) PrePrepare 链必须满足 previous.CurState == current.LastState。
每条显式边还要统一检查：引用存在、无自环、前置结束时间不晚于当前开始时间、 两端至少通过机器人/站点/材料之一有关联、PJobName 在双方都存在时一致。整张图还要检查 PreMoveID 重复和环路。

6. LoadLock 压力态专项检查

  • 同一 LoadLock 的 PrePrepare(10) 按时间排序后，连续转换必须首尾相接。
  • Pump/Vent 期间，不允许同一 LoadLock 上发生 Pick、Place、Prepare、Complete。
  • entry LoadLock：in_robot 访问侧为 ATM，out_robot 访问侧为 VAC。
  • exit LoadLock：in_robot 访问侧为 VAC，out_robot 访问侧为 ATM。
  • Pick/Place 访问 LoadLock 时，实际压力态必须等于机器人要求的压力侧；处于转换中直接非法。

7. 错误分类

前缀含义典型问题
ML 字段违例 字段缺失、类型错误或枚举不支持。 MoveID 非正整数、PreMoveID 不是整数列表、SlotList 为空。
ML 拓扑违例 违反 init data 中的设备结构。 机器人不可达模块、槽位不在 Slots 内、模块不存在。
ML 时长违例 实际时长和 init data 配置不一致。 PickTime、PlaceTime、PrepTransTime、Pump/Vent 时间不匹配。
ML PreMoveID ... 依赖图或依赖边非法。 缺少必要前置、引用不存在、前置未完成、类型违例、资源不关联、有环。
ML 压力态违例 LoadLock 压力链或访问侧非法。 转换中访问、压力状态不匹配、PrePrepare 链断裂。
