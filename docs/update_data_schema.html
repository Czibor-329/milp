update_data 字段说明

可视化接口数据结构 · 点击「说明」「PetriRunner 来源」列可编辑（自动保存）
JSON 顶层有 10 个字段，每次步进后由模拟器序列化并推送给可视化前端。

Robots

所有机器手的状态。键为机器手实名（TM1/TM2/TM3），值包含臂信息、状态和可用时间。

类型：dict[str, RobotInfo]

TM1TM2TM3

Stations

所有腔室 / 传送臂 / 端口的当前状态，包括门状态、工件数、工艺变量等。

类型：dict[str, StationInfo]

PM1PM2PM3 CoolLALB LCLDP1 P2P3

Materials

所有 wafer 的完整状态列表（含当前位置、路线、优先级等）。

类型：list[MaterialInfo]（长度 = wafer 总数）

25 个 wafer

ProcessJobs

工艺作业列表。每个 PJob 对应一批需要按同一路线加工的 wafer 组。

类型：list[ProcessJob]

ControlJobs

控制作业列表。管理多个 ProcessJob 的调度顺序与优先级。

类型：list[ControlJob]

MoveStates / RemoveList

MoveStates：进行中的移动事件（通常为空列表，事件触发时填充）。

RemoveList：待移除的 wafer ID 列表。

ProcessRecipes

工艺配方字典，key = 配方名，value = 配方参数。当前示例为空列表。

InitialMoveID / CurrentTime

InitialMoveID：本次推送起始 move 序号（用于增量同步）。

CurrentTime：当前仿真时间（秒）。对应 PetriRunner.time。

三个机器手：TM1（大气侧）和 TM2/TM3（真空侧）。每个 TM 单臂（ArmA），运行时只输出 ArmInfo / State / TimeToAvailable 等动态字段。
