# 启发式与搜索策略

## `heuristic`：快速启发式

入口是 `start_schedule(ir, verbose=True)`。它固定加工腔的 round-robin 分配，只搜索各资源与机器手的服务顺序，并对每个候选同时评估普通 LoadLock 与 swap 变体。

- **backward 基线**：默认排序偏好更下游的 hop，倾向先排空再上料；它始终先被评估，是安全、驻留友好的比较地板。
- **单 route 喂片**：优先“放入加工腔”，其次“从 source 发新片”，最后才按默认排空规则。目标是让 LoadLock 持续装未加工片并填满并行 PM。
- **多 route 配比**：在 `1:1`、`1:2`、`2:1`、`1:3`、`3:1`、`2:3`、`3:2` 的前两 route 发片配比中逐一试验；其他 route 配额固定为 1。每个配比仍受 Banker 安全检查。
- **清洁处理**：含 dummy-WAC 时直接使用排空优先，以免未加工片占满 LoadLock，阻塞 dummy 或换出片。其他清洁类型仍可尝试喂片。
- **驻留回退**：若上述结果不可行，使用 `reserve=True` 预留后续资源，牺牲吞吐以换取 q-time/residency 可行性。

适合低时延默认排程。它不是全局组合优化，但由于每个试验都精确定时并与 backward 地板取优，结果单调不劣于该基线。

## `random`：随机 rollout

入口仍是 `start_schedule(..., random_orders=N, seed=S)`。先运行完整 `heuristic` 取得基底；然后进行 N 次 rollout。每一步将合法候选随机打乱，Banker 从随机偏好中选择第一个安全动作；每个完整定序以 `swap=True` 解码并精确定时。仅可行且 makespan 更小的结果会替换基底。

默认命令行次数为 64。它适合在不改变模型、可接受额外运行时间时获得廉价的多样性改进；固定 `seed` 可复现。

## `search`：双作业限时结构化搜索

入口是 `start_schedule(..., search_seconds=T, seed=S)`，仅在恰好两条 route 时生效，否则原样返回启发式基底。route 内 FIFO 不变，搜索对象是两条有序发片序列的**交织**。例如两边各 6 片时共有 924 种交织，远小于全部排列。

在预算的初段，搜索跨多个发片间距与 swap 口径的 portfolio；组合数不超过 10,000 时可系统枚举交织，否则随机去重采样。余下时间优先完整覆盖常用间距。若精确定时仅因 residency 超限失败，策略会把对应 `PM -> 下游` hop 的优先级提前一次后复评。所有已采纳的结果均已通过精确定时。

适合双 route 且可为每个实例投入默认 7 秒的场景；对多 route 不应期待效果。
